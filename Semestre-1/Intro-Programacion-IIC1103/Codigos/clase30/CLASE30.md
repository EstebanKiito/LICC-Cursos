# Clase 30 — Problema integrador final

Cierre del curso con un ejercicio que combina todo lo aprendido.

- **Listas de listas para modelar un sistema real**: líneas de metro
  representadas como `[nombre_linea, [estaciones]]`.
- **Búsqueda con bucles triplemente anidados** para encontrar estaciones de
  combinación (presentes en más de una línea).
- **Ordenamiento personalizado** del resultado final con `sort(key=criterio)`.

Combina manejo de listas de listas, búsqueda y ordenamiento con criterio
propio en un solo problema — del nivel de las evaluaciones del curso
(`ordenamiento- metro A.py`).

---

**Progresión general del curso**: variables y tipos → input/output →
condicionales (`if`/`elif`) → bucles (`while`/`for`) → funciones → strings y
slicing → listas y listas de listas (matrices) → recursión → archivos (I/O)
→ POO (clases, objetos, composición, operadores) → algoritmos de
ordenamiento → problema integrador final.
