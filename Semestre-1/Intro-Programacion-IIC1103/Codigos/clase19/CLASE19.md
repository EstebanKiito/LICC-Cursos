# Clase 19 — Listas de listas (matrices)

- **Recorrer una matriz**: usar un doble `for` para visitar cada elemento de
  una lista de listas, accediendo con doble índice `L[i][j]`
  (`lista de listas recorrer y buscar.py`), y buscar un valor específico
  dentro de ella usando también `count()` sobre sublistas.
- **Modelar relaciones de datos sin clases**: `simpsons.py` define las
  funciones `hijos(a, n)` y `padres(a, n)`, que recorren una lista de listas
  que representa un árbol genealógico (cada elemento es `[nombre,
  [índices_de_hijos]]`) para encontrar relaciones de parentesco por nombre e
  índice.

Ejemplos: `lista de listas recorrer y buscar.py`, `simpsons.py`.
