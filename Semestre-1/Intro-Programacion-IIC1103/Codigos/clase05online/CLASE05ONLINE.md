# Clase 05 (online) — Condicionales `if`/`else`

Primer contacto con la toma de decisiones en el código.

- **`if` / `else`**: cómo el programa elige un camino u otro según se cumpla
  o no una condición (`lanzar dado.py`).
- **Operadores lógicos `and` / `or`**: cómo combinar varias condiciones para
  expresar reglas más complejas, como las de un juego de piedra-papel-tijeras
  (`cachipun.py`), usados junto con `random.randint` para el azar.
- **Estructura de un programa Python**: `main.py` muestra la plantilla típica
  que genera un editor (PyCharm), con una función simple y el patrón
  `if __name__ == '__main__':`, que verán repetido más adelante al organizar
  código en funciones y módulos.

Ejemplos: `cachipun.py`, `lanzar dado.py`, `main.py`.
