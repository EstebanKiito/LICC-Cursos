# Clase 17 — Algoritmos clásicos sobre listas

- **Criba de Eratóstenes** (`eratostenes.py`): algoritmo clásico para
  encontrar números primos, usando una lista que se va "limpiando" con
  `remove()` y un `while` que se repite hasta vaciarla, junto con `min()`
  para encontrar el siguiente número a tachar.
- **Funciones anidadas y bucles múltiples** (`ultimo ejercicio i1.py`): contar
  substrings con traslape y encontrar el substring repetido más largo de un
  texto, usando dobles y triples `for` — un buen ejercicio de combinar
  funciones, strings y listas en un problema más desafiante (nivel de
  evaluación/interrogación).

Ejemplos: `eratostenes.py`, `ultimo ejercicio i1.py`.
